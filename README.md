
# SmartTask Landing Page

**Live Demo:** [https://dvornikov-prog.github.io/smarttask-landing/](https://dvornikov-prog.github.io/smarttask-landing/)

SmartTask is a clean, modern, and responsive landing page built with **HTML**, **CSS**, and **JavaScript**.

## 🚀 Features

- Fully responsive layout (mobile, tablet, desktop)
- Clean HTML structure and semantic elements
- Custom CSS for styling and layout
- JavaScript form validation and interactivity
- Simple, professional design for showcasing services or products

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, media queries)
- JavaScript (vanilla)

## 📂 Structure

```
smarttask-landing/
├── index.html       # Main HTML file
├── style.css        # Styling
└── script.js        # JavaScript for form validation
```
